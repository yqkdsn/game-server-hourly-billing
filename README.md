## 为什么"按小时"在国内游戏服市场这么难找

按量付费在公有云是标配，但那套计价搬到游戏服上通常不划算：按量套餐的单价偏高，公网带宽、流量另算，一小时的费用经常比"月付除以 720 小时"还贵。对每月只开二三十小时的学生党来说，省钱的部分全被单价吃掉了。

雨云的做法是折中——保留一个很低的基础租金，把"用得多不多"这部分交给用量结算，按天出账。所以你会看到它的产品页写着"动态计费"和"按天计费"，而不是"按小时计费"。名字不同，解决的问题是一样的。

## 动态计费：CPU 闲着你就不花钱

这是雨云游戏云的主推模式，官方说明写得很直白：动态计费 = 低价基础月租/日租 + 每日对 CPU 超额使用率单独日结，也就是俗称的"CPU 电费"。内存、硬盘、带宽都不产生电量。

关键规则两条：

- **CPU 使用率基准值是 20%。** 低于 20% 视为不耗电，超过 20% 的部分才计费。
- **计费按天结算。** 当天用掉的电量，第二天从余额或积分里扣。余额和积分都能用来兑换电量，扣完就会进入限制状态，所以选动态模式要预存一点余额。

电量单价和 CPU 机型直接挂钩，越新的高主频芯片单价越高：

| CPU 机型 | 电量单价 |
| --- | --- |
| E5 2666v3、Platinum 8259cl | 0.0005 元 / 电量 |
| Gold 6146、Platinum 8275cl | 0.0006 元 / 电量 |
| Ryzen 5900X、EPYC 7A23 | 0.0008 元 / 电量 |
| 9950X、7950X、13900K、14900K | 0.001 元 / 电量 |

光看单价没感觉，雨云官方给的换算例子更直观：2666v3 的 2 核服务器，1 元约等于 2000 电量，够 70% 的 CPU 占用跑 7 小时；换成 5900X 的 2 核，1 元约等于 1200 电量，只够 70% 占用跑 4 小时。

## 按天日付：今天不开服，今天就不扣

面板服还能叠一层"按日计费"。它和动态计费都是日结，区别在于结算方向：

- 按日计费是每天定时用余额结算**下一天**的日租，面板服专供；
- 动态计费是每天定时结算**上一天**的 CPU 消耗。

直白点说，按日模式让你可以"今天关机，今天不花钱"。雨云论坛早期介绍面板服时给出的起步价是 4.3 元/月起，配合"当天不开服不扣费"的表述。这个数字属于早期资料，现在看更适合当成一个数量级参考，实际价格以购买页的实时报价为准——毕竟机型、机房和防护档位都会改价。

## 什么时候反过来选固定计费更划算

动态计费不是万能钥匙。它是靠"低基础租金 + 用量后付"来省钱的，前提是你的服务器大部分时间确实闲着。一旦 CPU 长时间高于 20%，后付的部分会一路累加，反而比固定计费贵。

雨云官方论坛里有个用户记录了自己的实测：一台 8275cl 的 3 核 6G 1.21 生存服，下午 16:00 到 18:00 三个在线玩家，两小时烧掉 400 多电量，一天下来接近 1000 电量，折算一个月约 30 元电量费——而同一机型改成固定计费，每月只多交 30 元左右。两边基本打平。他的另一台空岛服情况相反，3 到 4 人一天 600 多电量，一个月约 17 元，固定计费要多交 35 元/月，动态计费明显更赚。

这是论坛用户的一手记录，不是官方承诺，但结论方向是站得住的：**生存服、多人常驻服、模组整合包服，CPU 常年压不到 20% 以下，直接选固定计费；朋友聚会式的短时开服、测试服、空岛这类低占用玩法，动态计费更便宜。**

## 几个经常被问到的问题

**它到底算不算按小时计费？**
严格说不算。动态计费是按天结算 CPU 超额用量，按天日付是按天结算租金。但对于"一周只开几个晚上"的用户，最终账单和按时长付费的体感很接近，而且不用为关机的时段付钱。

**动态计费会不会突然扣很多？**
会，如果 CPU 长期跑高。1 元在 5900X 的 2 核机器上大概只够 70% 占用跑 4 小时。所以选动态模式时必须预存余额，余额和积分都用完后机器会进入限制状态，服务端会直接受影响。

**能中途换配置吗？**
可以随时升降配，也能弹性调整硬盘和带宽。小服起步、人多再升，比一次性买大配置更省钱。

**什么情况不建议选它？**
24 小时满载的高频服、重度整合包长挂、需要独享物理核或大型高并发业务的，按月固定计费或直接上裸金属更合适。另外高防独立 IP 要加钱，如果防御是刚需，这部分预算要单算。

一句话收尾：如果你搜"游戏服务器按小时计费"是因为不想为不开服的日子付钱，那雨云的动态计费加按天日付，确实把这件事解决得比较干净——前提是你把它当"按天算账"而不是"按小时算账"来理解，并且愿意花 1 块钱先试一天。
